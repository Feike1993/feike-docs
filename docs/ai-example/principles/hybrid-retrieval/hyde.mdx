## 流程步骤

1. **生成假想段落** — Chat 写百科风格段落；失败时回退原问题检索。  
2. **Embedding 假想段落检索** — `similaritySearch` 的 query 是假想正文，不是用户原问。  
3. **生成仍用原问题 + 真实 sources** — 假想段落可预览，绝不写入 sources。

## 应用场景

- 问句短、文档长、措辞差异大的知识库。
- 与 rewrite / none 对照评估查询扩展收益。
