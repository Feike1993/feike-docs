## 流程步骤

1. **双路召回** — 向量路用 pgvector 相似度；关键词路用 PG 全文 GIN 索引。两路各自产出 ranked list。  
2. **RRF 融合** — 不手工加权两路分数，而是按排名倒数求和（默认 k=60）。  
3. **与基础 RAG 的关系** — ingest / Embedding / 表结构不变；ingest 后额外建 content 全文索引。

## 应用场景

- 文档含 API 名、工单号、产品代号。
- 既有口语问法又有精确关键词的知识库。
