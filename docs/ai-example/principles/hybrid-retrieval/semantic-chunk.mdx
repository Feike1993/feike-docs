## 流程步骤

1. **标题切** — 在 `#{1,3}` 标题行前切开，标题留在下一块开头。  
2. **空行切段落** — 按连续空行切段落；空节仍保留标题锚点。  
3. **首段注入标题前缀** — 同节首段加标题前缀，便于 Embedding。  
4. **软合并到 chunk-size** — 再与 token 语料双 corpus 并存对照。

## 应用场景

- 技术文档、手册等标题层级清晰的语料。
- 评估「结构感知切」相对固定长度切的收益。
