## 流程步骤

1. **语义切父块** — 复用语义分块得到结构完整父段。  
2. **硬切子块** — 对每个父段按 `childSize` 硬切。  
3. **只入库子块** — metadata 含 `parentId`、`parentText`；父块本身不入 VectorStore。  
4. **命中后 expand** — 按 `parentId` 去重，用父全文拼 LLM 上下文。

<LogicPair
  leftTitle="优点"

      <li>`expand` 关闭时生成上下文又变回短块。</li>
    </ul>
  }
/>

## 应用场景

- 章节较长、需要精召回又要完整段落生成的文档 QA。
- 对比「只检索子块」与「展开父块」对答案质量的影响。
