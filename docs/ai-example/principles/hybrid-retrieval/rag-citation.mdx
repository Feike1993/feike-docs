## 流程步骤

1. **检索** — 与现有 RAG 相同；空检索仍走拒答。  
2. **别名上下文** — 拼 `C1..Cn` + allowlist。  
3. **结构化答** — `{answer, citations}`。  
4. **归一化与校验** — resolve 后 validate；失败返回 `CITATION_REFUSAL`。
