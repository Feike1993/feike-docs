## 流程步骤

1. **Harness 里的 Evaluator** — 与 Memory / Tools / Agent 并列；只做最小 offline 断言。  
2. **target 枚举** — `tools | agentReact | rag | multiagent`，复用现有样例。

<LogicPair
  leftTitle="优点"
  left={
    <ul>
      <li>可脚本化、可进 CI 思路清晰。</li>
      <li>复用已有样例目标，增量加 case 成本低。</li>
      <li>失败信息比「感觉不对」可定位。</li>
    </ul>
  }
  rightTitle="缺点"
  right={
    <ul>
      <li>本仓是最小断言，非完整评测平台。</li>
      <li>断言过严易脆，过松易漏。</li>
      <li>不覆盖线上真实流量分布。</li>
    </ul>
  }
/>

## 应用场景

- 改 Prompt / 工具 / 检索后的冒烟回归。
- 演示「评测在 Harness 中的位置」。
