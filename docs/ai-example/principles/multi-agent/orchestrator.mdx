## 流程步骤

1. **编排者结构化决策** — `StructuredOutputInvoker` 解析 `next=researcher|writer`。  
2. **调研专员复用 ReAct** — 挂 DemoTools，受限 `maxWorkerSteps`，材料写回。  
3. **执笔专员无工具** — 只根据材料生成最终答复。

  }
/>

## 应用场景

- 先检索/算数再成文的报告类任务。
- 需要「调研」与「写作」权限隔离的流程。
