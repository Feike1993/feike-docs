# 可观测与审计

对应生产路径 `com.feike.ai.production.observability` 与 `audit`。教学 [TokenUsage](../principles/observability/token-usage) 解决「这一轮花了多少 token」。工业页还要解决：浏览器不能拿着用户 JWT 去刮 Prometheus，审计也不能把问句原文堆在表里。

## 流程步骤

1. **快照**  
   `GET /ops/snapshot` 返回问答次数、空检索、护栏、工具拒绝、入库任务等 `prod_*` 计数。匿名打 `/actuator/prometheus` **不是** 200。

2. **刮取**  
   Compose 里 Prometheus 的 Bearer 必须与 `PRODUCTION_METRICS_TOKEN` 一致。改 token 要两边一起改。云托管 Grafana 本仓不做。

3. **审计**  
   登录、工具探针、媒体探针都会落 `prod_audit_log`。问题只存 sha256。写入在虚拟线程里，失败只打日志，**绝不改变**业务响应——审计挂了不能让问答 500。

4. **时间线**  
   `GET /ops/runs/{runId}` 从 SSE 事件日志抽 step。过期、不存在、别人租户都是 `run_not_found` 404。真 Agent 本机选跑后，可观测面板才能加载与直播一致的步骤。

5. **压测摘要**  
   没跑过 k6 时 `GET /ops/loadtest` 404。跑完 `./loadtest/run.sh smoke` 后工业页能看到 reqs / p95。见 [Grafana k6](/docs/tech-stack/loadtest/k6)。

## 应用场景

- 工业页要有「能给访客看」的指标，而不能给访客 Prometheus。
- 需要证明工具拒绝发生过，又不把问句写进审计表。

## 设计取舍

| 选择 | 取舍 |
| --- | --- |
| 浏览器不刮 Prometheus | 少一个攻击面；多一个 snapshot 聚合 |
| 审计失败吞掉 | 主链路更稳；可能丢审计 |
| 时间线 404 而非 410 | 不暴露存在性；排障少一种精确状态 |

## 刻意不做

- 不做 LangSmith 级追踪产品  
- 不做云托管 Grafana  
- 不把问句原文写入 prod_audit_log
