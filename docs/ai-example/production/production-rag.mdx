## 流程步骤

1. **语料带租户**  
   检索过滤 `tenant_id`（及工业 corpus）。教学对照页的「全局演示语料」不能直接当成生产隔离。

2. **扩展 opt-in**  
   `queryExpansion=none|rewrite|hyde`。打开 rewrite/HyDE 要额外 LLM，本机选跑；工业页默认「无扩展」，不带该参数的流式 URL 与现在一致。

3. **假想文档不进 sources**  
   HyDE 段落只用于 embedding 检索，回答仍只接地真实切片，避免把模型臆造写进引用列表。

4. **少一路仍回答**  
   `RagKeywordRetriever` 不存在时退回纯向量。少一路召回还能答；直接失败不能。

5. **空检索拒答**  
   无命中发固定拒答 delta 后 done，不调 LLM。有图时图片本身是上下文，规则见 [媒体探针](./media-probe)。

6. **citation fail-closed**  
   生产护栏在输出侧要求可校验引用，失败 422，不是警告。算法细节见教学 [强制 Citation](../principles/hybrid-retrieval/rag-citation)。

## 应用场景

- 把 cookbook 的 Hybrid/HyDE 接到产品时，先关掉默认扩展。
- 需要「没索引就拒绝」而不是「没索引就胡说」。

## 设计取舍

| 选择 | 取舍 |
| --- | --- |
| 扩展默认关 | 省一趟 LLM；召回对短问可能变弱 |
| 全文可缺省 | 少依赖；少一路召回 |
| 空检索不调模型 | 省幻觉；用户看到的是固定文案 |

## 刻意不做

- 不重写 RRF / HyDE / 语义分块算法页  
- 不做在线学习排序 / ColBERT / GraphRAG  
- 不把教学 `POST /rag/ingest` 当成工业验收（那条仍同步、匿名）

异步重建索引：见 [异步入库](./ingest-stream)。
