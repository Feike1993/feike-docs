# 教程简介

让我们用 **不到 5 分钟** 了解 Docusaurus。

## 开始之前

先 **创建一个新站点**。

或者直接在 **[docusaurus.new](https://docusaurus.new)** 上 **立即试用 Docusaurus**。

### 你需要准备

- [Node.js](https://nodejs.org/en/download/) 20.0 或更高版本：
  - 安装 Node.js 时，建议勾选所有与依赖相关的选项。

## 生成新站点

使用 **classic 模板** 生成一个新的 Docusaurus 站点。

运行下面的命令后，classic 模板会自动加入你的项目：

```bash
npm init docusaurus@latest my-website classic
```

你可以在 Command Prompt、Powershell、Terminal，或代码编辑器自带的终端中输入该命令。

该命令还会安装运行 Docusaurus 所需的全部依赖。

## 启动站点

启动开发服务器：

```bash
cd my-website
npm run start
```

`cd` 命令用于切换工作目录。要操作刚创建的 Docusaurus 站点，需要先进入对应目录。

`npm run start` 会在本地构建网站，并通过开发服务器提供访问，地址通常是 http://localhost:3000/。

打开 `docs/intro.md`（也就是本页）并修改几行内容：站点会 **自动重新加载** 并展示你的更改。
