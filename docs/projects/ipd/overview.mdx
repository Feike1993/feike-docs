# 项目总览

**IPD 研发管理**（Integrated Product Development）是南都研发数字化后台：把立项、项目、任务、需求、变更、试产、问题跟踪串成可审批、可授权、可对接流程中心 / 钉钉 / PLM 的一套服务。代码仓是单体后端 `narada-ipd-server`，POM 描述为「研发管理」。

| 项 | 内容 |
| --- | --- |
| 角色 | 项目负责人 |
| 时间 | 2022.10 – 至今 |
| 职责 | 架构、核心功能、权限、跨系统集成与全流程迭代 |
| 成果 | 2023 年 7 月上线，项目/任务/审批持续迭代，多系统数据互通 |

## 一句话定位

本仓是 **Spring Boot 3.5.9 / Java 21 单体域服务**（HTTP 8099，context `/narada-ipd-server`，Nacos namespace `bos`）。它是公司服务舰队里的一员，**不是**仓内再拆成多个微服务。前端在 BOS / H5，不在本仓。

## 业务域地图

| 域 | 本仓有什么 |
| --- | --- |
| 项目 | `ipd_data`、立项（产品开发 / 基础研究）、子项目、模板、目标、成员角色 |
| 任务 | 任务树、里程碑、交付物、工时、导入 |
| 需求 | 需求导入与审批 `ipd_dm` |
| 变更 | 项目设计变更 `ipd_idc`、工程变更 `ipd_ec` |
| 试产 | `ipd_trial_produce` |
| 问题 | 多代问题单、措施、旧 OA 问题流 |
| 物料 | 项目物料、PLM 零件（`@DS("plm")`）；**没有**「物料申请」审批 Factory |
| 评审 | OA `KmReviewMain`（Oracle）、会审配置；**没有**名为「质量评审」的 Factory |

## 文档口径不要夸的几件事

- 「微服务架构」= Nacos 注册的单模块服务，对接权限中心、流程中心等外部服务
- 幂等 = Redis `setIfAbsent`，不是 Lua；SpEL 键解析器有，现网多用默认 MD5 键
- EasyExcel 导入 = 暂存 + 人员消歧，不是 SSE 百分比进度
- 审批策略覆盖问题/任务/变更/试产/立项/需求等，不要写成物料申请、质量评审两条独立策略类
- 列权限 Feign 几乎无业务调用；主路径是行授权 + 项目资源字段权限
