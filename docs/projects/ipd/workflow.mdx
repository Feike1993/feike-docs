# 审批流策略

流程中心只认「表名 + 回调接口」。IPD 用 **策略接口 + switch 路由**：新增一种审批，加一个 `FlowCallbackFactory` 实现并在 `FlowBackServiceImpl.getFactory` 里挂上，不必改流程中心。

接口 `com.nd.bpm.service.FlowCallbackFactory`：

- `getFlowData`：提交时的判断包
- `getLastVersionData`：审批人看到的最新业务包
- `updateByFlow`：节点流转时回写业务状态
- `getFlowTitle`：流程标题

## 路由表（BPM）

`FlowBackServiceImpl` 按 `tableName`：

| tableName | Factory | 单据 |
| --- | --- | --- |
| `ipd_im` / `ipd_ir` | `IssuesManagementFactory` | 研发问题 / 风险 |
| `ipd_im2` | `IssuesManagementNewFactory` | 问题管理 |
| `ipd_ims` | `IssuesMeasuresFactory` | 问题措施 |
| `ipd_task` | `IpdTaskFactory` | 任务 |
| `ipd_idc` | `IpdDataChangeFactory` | 项目设计变更 |
| `ipd_trial_produce` | `IpdTrialProduceFactory` | 试制 |
| `cpkf` / `jcyj` | `IpdProjectApprovalFactory` | 产品开发 / 基础研究立项 |
| `ipd_dm` | `IpdDemandFactory` | 需求导入 |
| `ipd_project_children` | `IpdDataChildrenFactory` | 子项目立项 |
| `ipd_ec` | `IpdEngineeringChangeFactory` | 工程变更 |

另有 MK/OA 路径 `IpdIssuesCallback`（`ipd_issues`），接口在 `com.nd.mk.service.FlowCallbackFactory`，是旧问题流。

合计约 **11** 个策略类。`BillDataEnum` 里还有更多立项变体，可共享同一 Factory。

## 和「物料申请 / 质量评审」的差别

物料在本仓是项目物料同步、PLM 零件查询，**没有** `*Materiel*Factory`。质量相关出现在问题单审批人、OA 评审表 `KmReviewMain`，**不是**独立的质量评审策略类。讲审批类型时用上表，不要套那两个名字。

## 接入方式

流程中心 HTTP 调 IPD 的 BPM 回调（`BpmController`）。旧 OA 走 `/mk`。两套并存，新单据优先 BPM + Factory。
