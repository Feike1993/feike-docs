## C. 怎么用这些资料

1. **Week 日程「必读」** → 优先 A/B 一手链接。  
2. **同周加深** → JavaGuide 对应专题，用来串概念与排错清单。  
3. **框架与 Anthropic 名词冲突** → 自己做对照表（见 [怎么学](./how-to-learn.mdx)），不要死记框架营销名。  
4. **版本会变** → 涉及 API、价格、GA 版本时，以官网当日文档为准。

## 一个月验收清单

- [ ] 责任链选题清晰，成功标准可验收  
- [ ] 流式调用 + 结构化输出（含服务端校验）  
- [ ] 单 Agent，3～5 个工具，工具描述经过迭代  
- [ ] 手写 loop 与框架 loop 至少各理解一套  
- [ ] ≥2 种 Anthropic workflow 有可运行实现  
- [ ] 小知识库 + 检索工具（Agentic RAG）+ 拒答策略  
- [ ] Golden Set ≥30，改动能对比好坏  
- [ ] 轨迹 / Token 或耗时可回放  
- [ ] 高风险动作人工确认；注入样例进评测  
- [ ] MCP 最小实验可演示  
- [ ] ≥3 人试跑 + Badcase 复盘文档  

未勾项按优先级排进第 2 个月，而不是同时开新平台项目。

## 第 2 个月预览

- MCP 在多服务下的鉴权、审计与工具目录治理  
- 多 Agent / handoff（组织责任边界），仍先保证单 Agent 稳定  
- 模型网关：路由、限流、fallback、成本归因  
- 更完整的评测平台与线上灰度  
- 可选：LangGraph / Spring AI Alibaba 等编排加深（有业务需要再上）
