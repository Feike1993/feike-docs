# 管理文档版本

Docusaurus 可以管理文档的多个版本。

## 创建文档版本

为项目发布 1.0 版本：

```bash
npm run docusaurus docs:version 1.0
```

`docs` 目录会被复制到 `versioned_docs/version-1.0`，并生成 `versions.json`。

此时文档会有 2 个版本：

- `1.0`：位于 `http://localhost:3000/docs/`，对应 1.0 版本文档
- `current`：位于 `http://localhost:3000/docs/next/`，对应 **尚未发布的最新文档**

## 添加版本下拉菜单

为了在各版本间顺畅切换，可以添加版本下拉菜单。

修改 `docusaurus.config.js` 文件：

```js title="docusaurus.config.js"
export default {
  themeConfig: {
    navbar: {
      items: [
        // highlight-start
        {
          type: 'docsVersionDropdown',
        },
        // highlight-end
      ],
    },
  },
};
```

文档版本下拉菜单会出现在导航栏中：

![Docs Version Dropdown](./img/docsVersionDropdown.png)

## 更新已有版本

可以在对应目录中编辑已版本化的文档：

- 编辑 `versioned_docs/version-1.0/hello.md` 会更新 `http://localhost:3000/docs/hello`
- 编辑 `docs/hello.md` 会更新 `http://localhost:3000/docs/next/hello`
