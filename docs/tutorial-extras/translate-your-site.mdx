# 翻译你的站点

下面以把 `docs/intro.md` 翻译成法语为例。

## 配置 i18n

修改 `docusaurus.config.js`，添加对 `fr` 语言环境的支持：

```js title="docusaurus.config.js"
export default {
  i18n: {
    defaultLocale: 'en',
    locales: ['en', 'fr'],
  },
};
```

## 翻译文档

把 `docs/intro.md` 复制到 `i18n/fr` 目录：

```bash
mkdir -p i18n/fr/docusaurus-plugin-content-docs/current/

cp docs/intro.md i18n/fr/docusaurus-plugin-content-docs/current/intro.md
```

然后将 `i18n/fr/docusaurus-plugin-content-docs/current/intro.md` 翻译成法语。

## 启动本地化站点

以法语环境启动站点：

```bash
npm run start -- --locale fr
```

本地化站点可访问 [http://localhost:3000/fr/](http://localhost:3000/fr/)，其中「开始使用」页面也已翻译。

:::caution

开发模式下，一次只能使用一种语言环境。

:::

## 添加语言下拉菜单

为了在各语言间顺畅切换，可以添加语言下拉菜单。

修改 `docusaurus.config.js` 文件：

```js title="docusaurus.config.js"
export default {
  themeConfig: {
    navbar: {
      items: [
        // highlight-start
        {
          type: 'localeDropdown',
        },
        // highlight-end
      ],
    },
  },
};
```

语言下拉菜单会出现在导航栏中：

![Locale Dropdown](./img/localeDropdown.png)

## 构建本地化站点

为特定语言构建站点：

```bash
npm run build -- --locale fr
```

或者一次性构建包含全部语言的站点：

```bash
npm run build
```
