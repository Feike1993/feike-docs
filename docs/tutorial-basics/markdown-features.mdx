# Markdown 功能

Docusaurus 支持 **[Markdown](https://daringfireball.net/projects/markdown/syntax)**，并提供一些 **额外能力**。

## Front Matter

Markdown 文档顶部可以包含称为 [Front Matter](https://jekyllrb.com/docs/front-matter/) 的元数据：

```text title="my-doc.md"
// highlight-start
---
id: my-doc-id
title: 我的文档标题
description: 我的文档描述
slug: /my-custom-url
---
// highlight-end

Markdown 正文内容
```

## 标题 {/* #my-heading-id */}

Markdown 标题使用标准的 “#” 语法，并会自动加入目录。`#` 的数量对应标题级别。

```md
## 标题

我的正文
```

### 标题 ID {/* #my-custom-id */}

在标题文本后添加 `{/* #my-custom-id */}`，可为标题指定显式锚点 id，便于链接跳转。

```md
### 标题 ID {/_ #my-custom-id _/}
```

## 链接

支持常规 Markdown 链接，可使用 URL 路径或相对文件路径。

```md
一起来看看如何 [创建页面](/create-a-page)。
```

```md
一起来看看如何 [创建页面](./create-a-page.mdx)。
```

**效果：** 一起来看看如何 [创建页面](./create-a-page.mdx)。

## 图片

支持常规 Markdown 图片语法。

可以使用绝对路径引用 `static` 目录中的图片（例如 `static/img/docusaurus.png`）：

```md
![Docusaurus logo](/img/docusaurus.png)
```

![Docusaurus logo](/img/docusaurus.png)

也可以相对当前文件引用图片。这很适合把图片和对应的 Markdown 文件放在一起：

```md
![Docusaurus logo](./img/docusaurus.png)
```

## 代码块

Markdown 代码块支持语法高亮。

````md
```jsx title="src/components/HelloDocusaurus.js"
function HelloDocusaurus() {
  return <h1>Hello, Docusaurus!</h1>;
}
```
````

```jsx title="src/components/HelloDocusaurus.js"
function HelloDocusaurus() {
  return <h1>Hello, Docusaurus!</h1>;
}
```

## 提示框（Admonitions）

Docusaurus 提供特殊语法来创建提示框和标注：

```md
:::tip[我的提示]

试试这个很棒的功能选项

:::

:::danger[注意]

此操作比较危险

:::
```

:::tip[我的提示]

试试这个很棒的功能选项

:::

:::danger[注意]

此操作比较危险

:::

## MDX 与 React 组件

[MDX](https://mdxjs.com/) 可以让文档更 **交互化**，并允许在 Markdown 中使用任意 **React 组件**：

```jsx
export const Highlight = ({children, color}) => (
  <span
    style={{
      backgroundColor: color,
      borderRadius: '20px',
      color: '#fff',
      padding: '10px',
      cursor: 'pointer',
    }}
    onClick={() => {
      alert(`你点击了颜色 ${color}，标签为 ${children}`)
    }}>
    {children}
  </span>
);

这是 <Highlight color="#25c2a0">Docusaurus 绿色</Highlight>！

这是 <Highlight color="#1877F2">Facebook 蓝色</Highlight>！
```
