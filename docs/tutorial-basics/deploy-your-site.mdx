# 部署站点

Docusaurus 是一个 **静态站点生成器**（也称为 **[Jamstack](https://jamstack.org/)**）。

它会把站点构建成简单的 **静态 HTML、JavaScript 和 CSS 文件**。

## 构建站点

为 **生产环境** 构建站点：

```bash
npm run build
```

静态文件会生成在 `build` 目录中。

## 部署站点

在本地测试生产构建：

```bash
npm run serve
```

此时 `build` 目录会通过 [http://localhost:3000/](http://localhost:3000/) 提供访问。

接下来，你几乎可以把 `build` 目录 **部署到任何地方**，而且通常 **免费** 或成本很低（详见 **[部署指南](https://docusaurus.io/docs/deployment)**）。
