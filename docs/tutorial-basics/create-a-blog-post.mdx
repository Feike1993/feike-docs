# 创建博客文章

Docusaurus 会为每篇博客文章创建 **独立页面**，同时还会生成 **博客列表页**、**标签系统**、**RSS** 订阅源等。

## 创建第一篇文章

在 `blog/2021-02-28-greetings.md` 创建文件：

```md title="blog/2021-02-28-greetings.md"
---
slug: greetings
title: 你好！
authors:
  - name: Joel Marcey
    title: Docusaurus 1 联合创建者
    url: https://github.com/JoelMarcey
    image_url: https://github.com/JoelMarcey.png
  - name: Sébastien Lorber
    title: Docusaurus 维护者
    url: https://sebastienlorber.com
    image_url: https://github.com/slorber.png
tags: [greetings]
---

恭喜，你已经写出了第一篇博客！

尽管去修改这篇文章，随意尝试各种写法。
```

新博客文章可访问：[http://localhost:3000/blog/greetings](http://localhost:3000/blog/greetings)。
