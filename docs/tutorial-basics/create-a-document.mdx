# 创建文档

文档是通过以下机制串联起来的 **页面组**：

- **侧边栏**
- **上一页 / 下一页导航**
- **版本管理**

## 创建第一篇文档

在 `docs/hello.md` 创建 Markdown 文件：

```md title="docs/hello.md"
# 你好

这是我的 **第一篇 Docusaurus 文档**！
```

新文档可访问：[http://localhost:3000/docs/hello](http://localhost:3000/docs/hello)。

## 配置侧边栏

Docusaurus 会根据 `docs` 目录 **自动创建侧边栏**。

添加元数据即可自定义侧边栏标签和顺序：

```md title="docs/hello.md" {1-4}
---
sidebar_label: '嗨！'
sidebar_position: 3
---

# 你好

这是我的 **第一篇 Docusaurus 文档**！
```

也可以在 `sidebars.js` 中显式定义侧边栏：

```js title="sidebars.js"
export default {
  tutorialSidebar: [
    'intro',
    // highlight-next-line
    'hello',
    {
      type: 'category',
      label: '教程',
      items: ['tutorial-basics/create-a-document'],
    },
  ],
};
```
