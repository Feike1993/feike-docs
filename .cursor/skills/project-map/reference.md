# 仓库地图

个人技术文档站（Docusaurus 3 + React 19 + pnpm），站点名「飞客」，部署到 GitHub Pages：`https://feike1993.github.io/feike-docs/`（`baseUrl=/feike-docs/`）。无后端 API；内容以 MDX 文档 + 静态资源为主。

| 区域 | 路径 | 说明 |
|------|------|------|
| 入口 / 站点配置 | `docusaurus.config.ts`、`sidebars.ts`、`package.json` | 站点元信息、navbar/footer、Mermaid、四条文档侧栏（autogenerated） |
| 文档内容 | `docs/` | 四大栏目：`ai`、`ai-example`、`tech-stack`、`projects` |
| UI / 首页 | `src/pages/index.tsx`、`src/components/Home/`、`src/data/profile.ts` | 个人主页；文案与数据在 `profile.ts` |
| 主题 / 品牌色 | `src/theme/`、`src/css/`、`src/components/BrandThemeSwitcher/`、`static/js/brand-theme-init.js` | 品牌主题切换；`Root` + navbar 自定义项 + FOUC 防闪脚本 |
| 架构图组件 | `src/components/ArchitectureDiagram/` | `ArchifyEmbed`（iframe HTML）、`DiagramFrame`、`LogicPair`、`SourceMap` |
| 静态资源 | `static/img/`、`static/diagrams/`、`static/js/` | 图：`ai-example` 下 Archify JSON+HTML；`ai` 下 draw.io/svg |
| CI / 部署 | `.github/workflows/deploy.yml`、`test-deploy.yml` | push `main` → build → GitHub Pages |
| 本地工具（gitignored） | `.tools/archify/` | Archify 技能/渲染器副本，不入库；用于生成 `static/diagrams` |

## 文档栏目（docs/）

| 栏目 | 路径 | sidebarId | 现状 |
|------|------|----------|------|
| AI 编程 | `docs/ai/` | `aiSidebar` | 有内容：`claude-code/`、`agent-learning/`、`diagramming-tools.mdx`；空目录占位：`agent-patterns`、`mcp`、`memory`、`observability`、`quality`、`rag` |
| ai-example | `docs/ai-example/` | `aiExampleSidebar` | 原则讲解页 + Archify 图；入口 `overview.mdx`；原则在 `principles/`（含 hybrid-retrieval / multi-agent / observability / quality / production） |
| 技术栈 | `docs/tech-stack/` | `techStackSidebar` | `deployment/`、`ide/`、`jvm/`、`loadtest/`（Grafana k6） |
| 项目经历 | `docs/projects/` | `projectExperienceSidebar` | `ime/`、`ipd/`、`qms/`（各含 overview / architecture / recap 等） |

侧栏均为 `{type: 'autogenerated', dirName: '...'}`，目录结构即导航；分类元数据看各目录 `_category_.json`。

## 常用定位

| 功能 | 关键路径 |
|------|----------|
| 改站点标题 / baseUrl / navbar | `docusaurus.config.ts` |
| 增删文档栏目或侧栏 | `sidebars.ts` + `docs/<dir>/` + config navbar items |
| 写/改文档页 | `docs/**/*.mdx` |
| 首页文案、经历、技能数据 | `src/data/profile.ts` |
| 首页区块布局 | `src/components/Home/*.tsx`、`src/pages/index.tsx` |
| 品牌主题列表 / 切换器 | `src/theme/brandThemes.ts`、`src/components/BrandThemeSwitcher/`、`src/css/brand-themes.css` |
| 文档内嵌 Archify 图 | MDX 中 `ArchifyEmbed`；产物 `static/diagrams/ai-example/*.html`；规格 `*.{architecture,dataflow,sequence,lifecycle}.json` |
| 画图工具选型文 | `docs/ai/diagramming-tools.mdx` + `static/diagrams/ai/` |
| Grafana k6 压测文 | `docs/tech-stack/loadtest/k6.mdx`；截图 `static/img/tech-stack/k6/` |
| 本地开发 / 构建 | `pnpm start` / `pnpm build`（勿用 npm/yarn） |
| 类型检查 | `pnpm typecheck`（`tsconfig.json`） |
| Pages 部署流水线 | `.github/workflows/deploy.yml` |

## 不要碰

- `node_modules/`、`build/`、`.docusaurus/`、`.git/`、`.pnpm-store/`
- `pnpm-lock.yaml` 巨物（除非刻意改依赖）
- `.tools/`（已在 `.gitignore`，本地 Archify 工具树）
- 生成物目录与锁文件以外的无关 IDE 缓存（`.idea/` 等）

## 备注

- 包管理：**仅 pnpm**（`packageManager: pnpm@11.4.0`，Node ≥ 20）。
- blog 已关闭（`blog: false`）。
- 中文站：`i18n.defaultLocale = zh-Hans`。
- `onBrokenLinks: 'throw'`，坏链会直接让 build 失败。
